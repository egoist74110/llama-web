本轮还独立检查了三个生命周期边界，没有改仓库测试：

1. **进程退出，采样始终不返回。** 加载失败在退出后 1.2 秒的验证期限内返回，不等待 5 秒采样超时；死亡 PID 不再存活，重复请求不取得旧端口。
2. **失败之后，采样才返回。** 模型保持 failed，不因晚到结果重新进入 ready。
3. **健康进程，采样报错或超时。** 两种情况下都允许进入 ready；永不返回的采样实际等待约 5000 ms 后放行，PID 仍存活。统计问题没有变成加载失败。
