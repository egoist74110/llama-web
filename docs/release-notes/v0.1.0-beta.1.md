llama-web 的首个 Windows 预发布版：本地私有 LLM 控制台，管理 llama.cpp（llama-server）并提供 OpenAI 兼容接口。

## 新增
- Windows 桌面版：双击打开管理界面（总览 / 模型 / 日志 / 设置），关闭主窗口即停止服务和所有模型进程
- 内置运行环境，不需要安装 Bun、Node、Rust 或 Git；首次运行可从旧版 llama-web 的 data 目录复制数据（原目录不变）
- 应用内更新：设置页「关于与更新」显示版本号、检查更新；有新版时提示并显示更新说明，可在应用内下载、校验后安装，也可跳过某个版本
- OpenAI 兼容接口 /v1/*：按请求里的 model 自动加载 / 切换模型，排队切换，图片压缩预处理
- llama.cpp 官方 Release 自动下载、校验、更新，并保留旧版本用于回退
- 可选公网入口（Cloudflare 隧道，仅 /v1/*，需要 API key）

## 安装前请看
- 系统：Windows 11 x64。只在一台装有开发工具和 NVIDIA 显卡的 Windows 11 上做过完整验收；没有在干净的 Windows、无 NVIDIA 显卡的电脑或较旧 CPU 上验证过
- 推理：检测到 NVIDIA 显卡（nvidia-smi）时下载 CUDA 版 llama.cpp，否则下载 CPU 版（速度慢很多；这条路径只在本机强制 CPU 时验证过）。也可以在数据目录的 settings.json 里把 llamacpp.acceleration 设为 cuda 或 cpu 后重启。CPU 指令集最低要求以 llama.cpp 官方构建为准，尚未实测
- 需要联网：安装包不含 llama.cpp 和模型，首次启动会从 GitHub 下载 llama.cpp（约数百 MB，CUDA 版含 cudart）；缺少 WebView2 时安装程序会联网下载。之后已下载的 llama.cpp 和模型可以断网使用
- 安装包**未做代码签名**：Windows SmartScreen 可能提示「已保护你的电脑 / 未知发布者」，需点「更多信息 → 仍要运行」。请只从本页面下载，并可用 SHA256SUMS 核对
- 模型文件不随安装包提供，在「设置 → 模型目录」中指向你自己的 .gguf 目录

## 升级与卸载
- 以后的版本：在应用的「设置 → 关于与更新」里检查并安装，或下载新安装包直接覆盖安装
- 覆盖安装和卸载都保留用户数据（配置、API key、模型目录引用、已下载的 llama.cpp）。卸载时不要勾选「删除应用数据」，否则会删除默认数据目录
- 需要回到旧版时，重新运行旧版安装包即可

## 已知问题
- 一键配置 Cloudflare 隧道时，如果进程恰好在两次配置写入之间被强制结束，下次需要重新预览并确认（不会自动恢复）
- cloudflared 实际连接日志的个别格式尚未完全确认，隧道状态文字可能不够准确
- 只提供 Windows x64；macOS、Linux、Windows ARM 暂不提供

- `llama-web-0.1.0-beta.1-manifest.json`：构建信息（提交、内置 Bun 版本、签名状态）
