llama-web 第七个预发布版，**首次同时提供 Windows 和 macOS（Apple Silicon）安装包**。相较 beta.6，新增内置聊天页，修复若干问题。

## 新增

- 内置聊天页「对话」：直接在应用里和已在线的模型流式对话，支持停止、重新生成、思考折叠、速度显示；多会话列表（新建 / 切换 / 重命名 / 删除确认）；带视觉文件（mmproj）的模型可上传图片。对话只保存在本机浏览器存储里，请求记录不含对话内容。没有在线模型时只提示，不会替你加载模型。
- macOS（Apple Silicon，arm64）安装包 DMG。**未签名、未公证**，见下文。

## 修复

- 恢复 `runtimes.json` 备份时，同一毫秒产生的多份备份可能选到较旧的一份。
- 模型目录填写 `~\models` 这类写法时，路径展开更稳妥。
- macOS 上停止进程组时，遇到尚未回收的退出进程不再报错。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。
- 首次打开的做法（尚未经过真机完整验证，以你实际看到的系统提示为准）：把 `llama-web` 拖进“应用程序”，双击打开被拦后，到“系统设置 → 隐私与安全性”找到“已阻止使用 llama-web”，点“仍要打开”。如果仍被拦，核对校验值后可在终端执行 `xattr -dr com.apple.quarantine /Applications/llama-web.app`。详见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 macOS 版 llama.cpp。
- **未在真机验证**：Metal 推理与模型加载、窗口里的完整使用、退出后的进程清理、“下载 → 拖入 → 首次打开”的完整流程。构建、包内 Bun（JIT、sharp）、启动服务、下载并执行官方 llama.cpp `--version` 已在 GitHub 的 macOS runner 上验证。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留，卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 llama.cpp。
- 未实测：聊天页发图（本机没有带视觉文件的模型）、构建产物里聊天页的流式表现、Windows 上的聊天页。
