llama-web 1.2.1：手动添加 llama.cpp 版本时，可以直接选择服务端程序文件，用于试用改了程序名的第三方 llama.cpp 分支。相较 1.2.0：

## 新增

- **「添加 llama.cpp 版本」多了「选择程序」**：直接选服务端程序本身，名字不必是 `llama-server`（例如某些分支叫 `llama-kvmem-server.exe`）。点「选择程序…」会在本机弹出系统的选择文件对话框，从你的用户目录开始；也可以直接粘贴路径。对话框里写明了程序通常长什么样（Windows：`llama-server.exe`；Mac：没有扩展名的 `llama-server`，Finder 显示为「Unix 可执行文件」）。
- 会把程序所在的**整个文件夹**（含 .dll / .dylib）复制进 llama-web 使用，所以那个文件夹里最好只放这一个版本。
- **读不到版本号也能添加**：用这种方式添加时，程序不支持 `--version` 也不拦，只提示一句；能不能用以实际加载模型为准。
- 分支自己的参数（例如 `--kvmem`）写在模型或方案的「额外参数」里；默认额外参数里如果有分支不认识的参数，请删掉。

## 已知限制

- 没有用真实的第三方分支实测加载模型；Mac 上只测了「选择程序 → 预览 → 添加」的流程（用一个改名的测试程序），Windows 上没有测试，系统的选择文件对话框也没有在真机上点开过。
- llama-web 不为任何分支做专门适配，也不负责它们的下载和更新；分支和官方 llama.cpp 参数不兼容时会照常报启动失败。
- 1.2.0 的已知限制（Vulkan / SYCL / ROCm 未在真机验证等）不变。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。

- `llama-web_1.2.1_macos-arm64.dmg`：macOS arm64 安装包（未签名、未公证）。
