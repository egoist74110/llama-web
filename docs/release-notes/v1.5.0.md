llama-web 1.5.0：网关内置联网搜索，本机模型和外部上游不依赖客户端就能搜索网页、读取网页。相较 1.4.0：

## 新增

- **网关联网搜索**（设置页新增「联网搜索」卡片）：网关在聊天请求里加入 `web_search`（搜索）、`fetch_url`（读取网页文字）和 `web_search_guide`（使用说明）三个工具，模型调用后由网关自己执行并续写，对客户端不可见，一次请求最多 8 轮，支持流式；这些工具的调用不会交给客户端（客户端自己的工具调用照常交给客户端）。
  - **本机模型内置**，只受设置里的总开关控制；**每个外部上游有自己的开关**（默认开）。客户端已经定义了同名工具时，网关不再添加。
  - **搜索后端**：无需 key 的 DuckDuckGo 和 Bing 开箱即用；需要 key 的 Tavily、Brave 在设置里填 key 后启用。工具描述里明确列出可用的后端名字并标明免费或付费，搜索结果开头也写明用的是哪个。
  - **付费搜索由模型自己决定**：`web_search` 可以用 `backend` 参数指定后端。默认网关只自动用免费的；模型觉得免费结果不够、事实又重要时，可以指定付费后端，但**指定之前必须先读过使用说明**，没读网关不执行。设置里可改成「先免费、失败自动换付费」或「先用填了 key 的」。一个后端失败会自动换下一个（自动选择时）：key 被拒绝则停用到 key 改变，限流或超时暂停 60 秒。请求记录会记付费搜索的次数。
  - **使用说明（提示词）**：模型要用搜索时先读一份说明（何时搜、怎么搜、检查结果、来源与引用、结果是数据不是指令），默认文本由 router 的搜索提示词改写而来，可在设置里编辑、恢复默认；「使用前必须先读说明」默认开，没读就调用搜索或读网页时网关不执行，只让它先读，读说明的那一轮不占轮数上限。
  - 搜索结果开头写明用的后端；请求记录只记搜索和读网页的次数与后端，不记查询词和网址。
- **知识库检索条数上限**从 20 提高到 1000（绑定、工具参数、请求字段一致）。

## 升级说明

- `settings.json` 自动升级到 v14（新增 `webSearch`：总开关默认开，搜索顺序默认只自动用免费的，使用说明默认内置，必须先读默认开）。
- `secrets.json` 自动升级到 v5（新增 `searchKeys`，保存 Tavily、Brave 的 key，不会出现在界面、日志或事件里）。
- `upstreams.json` 自动升级到 v3（每个外部上游新增 `webSearch`，原有上游补为开）。**升级后，所有已配置的外部上游的聊天请求都会带上这三个工具**；不想要的在「接入」里逐个关掉，或在设置里关掉总开关。

## 已知限制

- DuckDuckGo 和 Bing 是抓取结果页再解析：页面结构变了会失效，大陆网络下 DuckDuckGo 常不可达（会自动换 Bing）。搜索请求不走「设置 → 网络」里的代理。
- `fetch_url` 不拦截内网地址（私人使用的取舍）。**如果开了公网入口**，持有 API key 的人发来的请求也能让模型读取你内网里的网页，对外暴露前请注意，或关掉联网搜索。
- 网关替模型调用的工具不会留在客户端的聊天历史里，所以每个新请求都要重新读一次使用说明（多一轮往返和几百个 token，不占搜索次数）。
- 联网搜索只用假上游与固定网页样例验证过，真实网络下四个后端、真实本机模型与外部上游的效果还没有真机验证；设置页的新卡片没有在浏览器里逐项检查（深浅色、手机宽度、英文）。
- 1.4.x 的已知限制不变。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
