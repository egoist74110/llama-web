llama-web 第四个 Windows 预发布版。相较 beta.3，主要是首次启用体验改进和桌面版启动窗口修复。

## 新增与改进

- 模型启用 / 启动失败时统一弹窗说明原因并给出下一步；缺少 llama.cpp 运行库时可直接前往下载。
- 首次启用确认框新增上下文长度设置（可同时设为全局默认）。
- MTP 改为显式选择：默认关闭，开启后选「模型自带 MTP」或「草稿模型文件」；参数编辑共用同一控件。
- 思考开启时可设置思考 token 上限（0 = 不限制）。

## 修复

- 修复桌面版启动时短暂出现两个 llama-web 窗口：主窗口现在加载完成后才显示，不再与启动器同时可见。

## 安装、升级与验证范围

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留，卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 llama.cpp。
- 真实模型 / GPU 推理（含 MTP 与思考上限的实际效果）尚未实测；不提供 Mac 安装包，现有 macOS CI 仍未通过。
