llama-web 1.3.0：手动导入的 llama.cpp 可以设为全局使用的版本；下载在大陆网络下更可靠，下载不了时可以从本地导入。相较 1.2.1：

## 新增

- **手动添加的 llama.cpp 版本可以直接「使用」**：设置 → llama.cpp 版本里，手动添加的那一行现在有「使用」按钮，设为全局当前版本后所有没单独指定版本的模型都用它；添加成功后也可以一键「设为当前版本」。它的文件丢失时自动改用该通道最新的官方版本并提示，不改你的设置；自动更新不会替换你选的手动版本。
- **设置 → 网络**（新卡片）：
  - 代理：跟随系统（环境变量 / Windows 系统代理 / macOS 系统代理，不读 PAC）、手动填写（http / https，例如 Clash、v2rayN 的 HTTP 或 mixed 端口 `http://127.0.0.1:7890`；不支持 SOCKS）、不使用。只用于 GitHub、镜像与 Cloudflare 接口，不影响 `/v1` 转发和模型。
  - 下载来源：询问（默认，和以前一样失败后弹窗选镜像，弹窗可勾选「以后自动使用镜像」）、自动（直连失败后自动改用测速最快的镜像）、固定镜像。覆盖 llama.cpp、llama-web 更新、cloudflared 和从 GitHub 地址手动添加的版本。
  - 自定义镜像前缀移到这张卡片里。
- **校验更可靠**：走镜像下载时先尝试从 GitHub 官方取 SHA-256，取不到才用镜像提供的，界面会标出「校验值来自镜像」。
- **断点续传与自动重试**：大文件下载中断后接着下，一次操作内最多自动重试 3 次，最后仍按 SHA-256 校验。
- **下载失败时的本地兜底**：列出官方文件名，可「复制下载地址」用浏览器或其他方式下载，再点「从本地导入」。导入压缩包时可以附带 cudart 压缩包（Windows CUDA 版需要）；官方命名的压缩包读不到版本号时从文件名取。
- 「选择程序」添加时，程序文件名允许空格、括号和中文。

## 升级说明

- 设置文件自动升级到 v13（新增 `network`，默认：跟随系统代理、下载来源「询问」），原有设置不变。

## 已知限制

- 没有在大陆真实网络、也没有在 Windows 上实测（Windows 系统代理读取只有单元测试）；真实镜像下的断点续传没有实测。
- 「询问」模式下，cloudflared 和从 GitHub 地址添加版本失败时不会弹镜像选择（「自动」「固定镜像」模式下会走镜像）。
- 「自动」模式在直连被拦时，要等直连超时（每个请求 30 秒）才改走镜像。
- 活动日志里手动添加的版本仍显示内部编号 `custom:…`，不是名称。
- 从源码用 `bun run dev` 运行时代理设置不生效（开发模式跑在 Node 上）；安装包和 `start.bat` / `start.command` 正常。
- 1.2.x 的已知限制（Vulkan / SYCL / ROCm 未在真机验证、第三方分支未实测等）不变。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
