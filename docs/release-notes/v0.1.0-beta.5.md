llama-web 第五个 Windows 预发布版。相较 beta.4，只修复桌面版启动时窗口一闪而过的问题。

## 修复

- 桌面版启动时不再先弹出「正在启动本地服务」的启动器窗口再让它消失：正常启动直接显示主窗口；仅首次启动、数据导入恢复、启动失败、应用内更新，或启动超过约 2.5 秒时才显示启动器。
- beta.4 已修复启动器与主窗口同时可见的重叠，本版进一步消除启动器自身的一闪而过。

## 安装、升级与验证范围

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留，卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 llama.cpp。
- 窗口行为用发布版可执行文件轮询验证；冷启动很慢时的真机表现、真实模型 / GPU 推理仍未实测。不提供 Mac 安装包，现有 macOS CI 仍未通过。

## 文件

- `llama-web_0.1.0-beta.5_x64-setup.exe`：当前用户安装的 Windows x64 安装包。
- `SHA256SUMS`、`llama-web-0.1.0-beta.5-manifest.json`、`THIRD-PARTY-NOTICES.txt`、`LICENSE.txt`。
