llama-web 1.4.0：新增向量引擎与知识库，本机模型和外部上游都可以接上知识库；外部服务在 llama-web 重启后也能停止。相较 1.3.0：

## 新增

- **向量引擎**（模型页新增「向量引擎」页签）：单独起一个 `llama-server --embedding` 跑一个向量模型，不占在线模型数，不会被聊天模型挤掉；请求里 `model` 填引擎名即可调用。CPU / GPU 可切换（同一个 llama.cpp 版本）。请求记录也会从响应开头读取用量。
- **知识库**（新页面）：
  - 新建 / 编辑 / 删除知识库；点击或拖放上传 `.txt` / `.md`，显示文档状态与实时进度；有「检索测试」。
  - 检索为关键词（中文二元分词）+ 向量的混合检索，结果带出处与行号；没有向量引擎时可用「仅关键词」。
  - **标签与相似度阈值**：文档里单独一行 `[tag:a,b]` 作用到下一个标签行之前的内容，检索时可按标签过滤，避免同库不同类别串味；可设相似度下限（默认关）。
- **本机模型与外部上游可使用知识库**：每个模型 / 外部上游有独立开关（默认关）。可选全部知识库（之后新建的也算）或指定几个；方式分「注入」（把带编号出处的片段放进 system 消息）和「工具」（模型自己调用 `search_knowledge`，网关内执行，最多 3 轮，支持流式）。请求里也可带 `knowledge` 字段覆盖。请求记录里有知识库摘要。
- **外部服务停不掉的修复**：从「接入」页启动的服务会记录到 `data/run/upstreams-launched.json`，llama-web 重启后仍可点「关闭」；本机端口上不是 llama-web 启动的服务，可在确认框核对程序 / PID / 路径 / 端口后「强制停止」。

## 升级说明

- `upstreams.json` 自动升级到 v2（新增 `knowledge`，默认关）；模型的 `knowledge` 为可选字段，原有设置不变。
- 知识库数据在 `data/` 下，每个库一个 SQLite 文件。

## 已知限制

- 真实向量引擎下的向量检索与阈值、真实 llama-server / 外部上游的注入与工具模式，主要靠单元测试和假上游验证，真机验证还不充分。
- 旧文档没有保存原文：要用标签功能需先删除旧文档再重新上传。重建索引需要向量引擎开着。
- 50 MB 文本约 14 万块，超过 5 万块的软上限时页面会提示；上传大文件时解码切块会让服务卡几秒。
- 「强制停止」在 macOS 上没有实测。
- `/v1/kb/search` 与 MCP 接口还没有提供（计划中）。
- 1.3.x 的已知限制不变。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
