llama-web 第一个正式版（1.0.0）。相较 0.1.0-beta.8，新增英文界面、侧栏语言切换和「接入」页的关闭按钮。

## 新增

- 英文界面：界面、事件、接口错误提示（包括 `/v1/*` 给第三方客户端的错误）都有中文 / English 两套文案；在左侧栏的深浅色开关上方一键切换，立即生效，不用重启，选择保存在设置里。模型、参数方案和已保存的文件不受影响；默认语言仍是中文，默认设置下行为与 beta.8 一致。桌面版启动窗口按系统语言选择初始语言。
- 数字与时间格式跟随界面语言。
- 接入外部服务：服务通过「启动」按钮启动成功后，会出现「关闭」按钮，结束刚才从这里启动的进程（连同它启动的子进程）。只有这一次运行的 llama-web 启动的服务才能从这里关闭；重启 llama-web 之后、或在别处自己启动的服务不显示这个按钮。
- README 增加英文版（`README.en.md`）。

## 修复

- 接口错误不再把内部异常原文发给客户端（原文只留在服务端日志）；取消请求与上游无响应体时的提示也改为跟随界面语言。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。
- 首次打开的做法（维护者已在一台 Apple Silicon Mac 上实测可用）：把 `llama-web` 拖进“应用程序”，双击打开被拦后，到“系统设置 → 隐私与安全性”找到“已阻止使用 llama-web”，点“仍要打开”。右键打开等其他方式没有验证，新版 macOS 上可能无效。如果仍被拦，核对校验值后可在终端执行 `xattr -dr com.apple.quarantine /Applications/llama-web.app`（该命令本身未单独验证）。详见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 macOS 版 llama.cpp。
- 真机情况：维护者在 Apple Silicon Mac 上完成了下载、安装、首次打开和运行，没有发现问题；没有记录具体的 macOS 版本、芯片型号和模型。其他 macOS 版本（尤其 13 / 14）、不同机型和长时间使用没有验证。构建、包内 Bun（JIT、sharp）、启动服务、下载并执行官方 llama.cpp `--version` 在 GitHub 的 macOS runner 上验证。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留，卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 llama.cpp。
- 未实测：聊天页发图（本机没有带视觉文件的模型）、构建产物里聊天页的流式表现、Windows 上的聊天页。
