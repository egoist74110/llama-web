llama-web 1.2.0：Windows 上没有能用的 NVIDIA 显卡时（Intel、AMD、老 N 卡），可以试用 llama.cpp 官方的 Vulkan 版让显卡参与推理。这是**实验性功能**，还没有在 Intel / AMD / 老 N 卡真机上验证。相较 1.1.0：

## 新增（实验性）

- **Vulkan 运行库**：Windows x64 新增 llama.cpp 官方 Vulkan 版（只需显卡驱动，不需要 CUDA）。适用于 Intel Arc 独显、Intel / AMD 核显、AMD Radeon 独显，以及跑不了 CUDA 的老 N 卡。
- **没有能用的 N 卡时由你选择**：找不到 NVIDIA 驱动，或者 N 卡太老 / 驱动太旧、没有能跑的 CUDA 版时，「设置 → llama.cpp 版本」会请你在「CPU 版」和「Vulkan 版（实验性）」之间选，不再提示去手改 `settings.json`。自动模式不会替你选 Vulkan。
- **加速方式可以在设置页切换**（自动 / CUDA / CPU / Vulkan），重启 llama-web 后生效。
- **手动添加的运行库识别正确**：按目录里的文件识别 CUDA / ROCm / SYCL / Vulkan / CPU。以前除了 CUDA 一律当成 CPU，用 CPU 默认参数（`-ngl 0`），显卡不参与。SYCL（Intel）和 ROCm（AMD）只支持手动添加。
- **默认参数**：Vulkan / SYCL / ROCm 启动时不沿用 CUDA 默认开启的 flash-attn 和 K / V 缓存量化（你自己改过的值和方案里写的值照常生效）。
- **核显按共享内存估算**：Windows 上的 Intel / AMD 核显按共享系统内存计算能否放下模型，和 Mac 一样。
- **失败时的兜底与反馈**：实验性运行库启动失败时照常报错，不会自动切换。失败详情里可以「改用 CPU 版」（会先确认；把这个模型改用 CPU 版，去掉方案自己的运行库选择，指定的显卡设备改回自动；没装 CPU 版会先提示下载），也可以「复制诊断信息」（版本、后端、显卡、失败类型、日志末尾，已去掉路径、用户名和 key），贴到 Issue 里反馈。
- 所有 Vulkan / SYCL / ROCm 的地方都标了「实验性」，第一次下载 Vulkan 版前会确认。

## 修复

- 本机检测：算力 3.x 的老 N 卡（如 Kepler）以前不会被判为「CUDA 版用不了」，现在按 llama.cpp 实际提供的 CUDA 12 / 13 判断。
- 英文界面在手机宽度下，导航文字互相重叠。

## 已知限制

- Vulkan / SYCL / ROCm 都**没有在真机上验证**，欢迎有 Intel / AMD / 老 N 卡的用户试用后用「复制诊断信息」反馈。
- 实时显存条、看门狗和加载时的实测显存仍只支持 NVIDIA；其他显卡上这些功能只看系统内存，或按时间估算加载进度。
- Windows 核显是按显卡名字判断的，个别型号可能判断错。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。本版的 Vulkan 相关改动不影响 Mac。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
