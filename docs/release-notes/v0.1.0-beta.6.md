llama-web 第六个 Windows 预发布版。相较 beta.5，增加按本机配置的默认参数、GitHub 不可达时的镜像兜底、模型删除等功能。

## 新增

- 首次运行按本机配置默认参数：按最大 NVIDIA 显存（没有 NVIDIA 卡时按系统内存）给出上下文与批大小；内置额外参数精简。已有安装不会被自动改动，可在「设置 → 全局默认参数」点「按本机重新推荐」，预览新旧值并逐项勾选后才写入。
- 首次启动确认框与全局 / 单模型配置：常用项（上下文、思考与上限、MTP）置顶，其余折叠；可把首次填写的值设为全局默认。
- 模型删除：卡片和编辑抽屉里有删除按钮与二次确认，可选把模型 / 草稿 / 视觉文件移入系统回收站（运行中不可删，被其他模型共用的文件会跳过并提示）。
- 检查 / 下载更新被 GitHub 限流或连不上时：改用 github.com 页面兜底；你手动发起的检查、下载失败后，会弹窗让你选择公共镜像重试，只对这一次生效，自动检查不会使用镜像。「设置」里可另填一个自己的 https 镜像前缀，作为弹窗中的额外选项。
- 新手引导页重做，没有模型时左侧显示「新手引导」入口。

## 修复

- Cloudflare 一键配置：权限不足不再误报为 token 无效，向导教程按新版后台重写。
- llama.cpp 状态不再一直停在「正在检查」。

## 安装、升级与验证范围

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（settings 自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型，首次启动需联网下载 llama.cpp。
- 未实测：Windows 上的首次调参数值、回收站删除、镜像在大陆网络下的可用性、真实模型 / GPU 推理。不提供 Mac 安装包，现有 macOS CI 仍未通过。
