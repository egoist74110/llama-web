llama-web 第二个 Windows 预发布版：界面整体重新设计，功能和配置不变。

## 变化
- 新界面：左侧栏导航（桌面宽度下侧栏固定，只有内容区滚动），浅色 / 深色统一的设计风格，Geist 字体随安装包提供，断网也能正常显示
- 总览：当前模型大卡（状态、已运行时长、实时生成速度和最近约 40 秒曲线）、显存 / 请求 / llama.cpp / 公网小卡、最近事件与最近请求
- 模型：已启用模型改为列表行，加载进度和失败原因直接显示在行内；扫描发现改为卡片；编辑抽屉分为「文件 / 配置方案 / 参数」三栏，命令预览和重复参数警告保留
- 日志：一行工具栏；模型输出为终端风格，事件为时间线，请求为表格
- 设置：左侧分区目录，卡片、开关、表单样式统一
- 行为规则、接口、配置文件结构都没有变；从 beta.1 升级后配置、API key、模型目录引用原样保留

## 安装前请看
- 与 beta.1 相同：Windows 11 x64；只在一台装有开发工具和 NVIDIA 显卡的 Windows 11 上做过完整验收，没有在干净的 Windows、无 NVIDIA 显卡的电脑或较旧 CPU 上验证过
- 需要联网：安装包不含 llama.cpp 和模型，首次启动会从 GitHub 下载 llama.cpp；缺少 WebView2 时安装程序会联网下载
- 安装包**未做代码签名**：Windows SmartScreen 可能提示「未知发布者」，需点「更多信息 → 仍要运行」。请只从本页面下载，并可用 SHA256SUMS 核对
- 本版新界面在源码版里逐页看过；安装包里的新界面只做了发布前的包内容检查，没有在干净机器上逐页试用

## 升级与卸载
- 在应用的「设置 → 关于与更新」里检查并安装，或下载安装包直接覆盖安装
- 覆盖安装和卸载都保留用户数据；卸载时不要勾选「删除应用数据」

## 已知问题
- 同 beta.1：一键配置 Cloudflare 隧道时进程恰好在两次配置写入之间被强制结束，下次需要重新预览并确认；cloudflared 个别连接日志格式未完全确认
- 只提供 Windows x64；macOS、Linux、Windows ARM 暂不提供
