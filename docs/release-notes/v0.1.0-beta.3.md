llama-web 第三个 Windows 预发布版。相较 beta.2，新增免域名临时隧道、llama.cpp 多版本管理、本机检测与设备选择、多 GPU 配置和用量统计，并调整自动更新行为。

## 新增功能

- 公网访问支持「没有域名，用临时地址」：无需 Cloudflare 账号或自有域名，自动获得临时地址；高级设置可切换自有域名 / 临时地址及 HTTP/2 / QUIC。临时地址每次启动可能变化，受 Cloudflare Quick Tunnel 的并发与流式限制，不适合作为稳定入口。
- llama.cpp 版本管理：可从本机目录、压缩包或 GitHub Release 添加版本，先预览再确认；可删除旧版本，最新官方版本受保护。模型和配置方案可指定版本，指定版本缺失时用同通道最新官方版本兜底并提示。
- 本机检测：设置页显示系统、CPU、内存、NVIDIA 显卡和驱动信息，自动选择兼容的 CUDA 运行库；Windows 分开管理 GPU / CPU 版本及默认参数，模型和方案可选择设备，并提供线程、NUMA 等 CPU 进阶参数。
- 多 GPU 配置：默认仍用单卡，自动选择显存最大的一张；可开启多卡并配置切分模式、比例和主 GPU。row / tensor 模式标为实验性，界面首次选用时要求确认，并记住相关加载失败。多 GPU 用于同一个模型，当前仍只允许一个模型在线；多模型并行尚未实现。
- 日志新增「用量」：按小时汇总请求、输入 / 输出 token、来源和模型，默认保留 30 天；不保存对话内容。
- 首次使用与模型目录：引导支持多个目录和系统文件夹选择；模型页可直接添加目录并扫描；新启用模型首次启动前可确认思考、视觉和 MTP 设置。

## 更新行为与修复

- llama.cpp 自动安装更新默认关闭；升级旧配置时也会关闭，但仍每天检查并在版本旁提示，用户可手动下载或重新开启自动更新。
- llama-web 自身默认开启检查与自动安装；升级旧更新偏好时会开启自动更新，保留跳过版本记录。桌面版自动更新会关闭当前应用、安装并重新打开；不希望自动安装时请在「设置 → 关于与更新」关闭开关。源码版只提供发布页链接。
- 关闭任一自动更新开关后，仍每天检查并提示，但不自动安装；检查记录跨重启保留，GitHub 限流有明确提示。新版提示放在版本旁，取消自动弹出的更新提示。
- 局域网访问时显示可供客户端连接的 LAN API 地址。
- `/v1/models` 不再重复列出内置「默认」方案；基础模型名和自建方案仍可用，已有的「名字:默认」调用继续有效。
- 修复隧道继承外部环境变量、临时地址日志解析、端口变更后的地址显示，以及运行库添加、删除和版本选择的审查问题。

## 安装、升级与验证范围

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名。SmartScreen 可能显示「未知发布者」，请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 安装包不含 llama.cpp 或模型，首次启动需要联网下载 llama.cpp；缺少 WebView2 时安装程序也会联网下载。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装。旧配置自动迁移；升级前建议备份用户数据。覆盖安装及卸载默认保留数据，卸载时不要勾选「删除应用数据」。
- 本版功能在 Windows 源码环境完成单元测试、类型检查及部分真机验证；真正的多 GPU 切分未实测，只有单卡参数验证。干净 Windows、无 NVIDIA 显卡、较旧 CPU、完整安装版界面与 beta.2 → beta.3 的自动升级仍需进一步试用。
- macOS 源码路径补充了启动脚本、文件夹选择、平台文案和扫描兼容处理，但现有 macOS CI 尚未通过，Metal 推理及 Mac 真机交互未验证。本版不提供 Mac 安装包，也不宣称 Mac 已支持；Linux、Windows ARM 同样不提供安装包。

## 已知问题

- 一键配置 Cloudflare 隧道时，若进程恰好在两次配置写入之间被强制结束，下次需要重新预览并确认；cloudflared 个别连接日志格式仍待核对。
- Quick Tunnel 的流式表现受服务端限制；长连接或稳定公网访问建议使用自有域名隧道。
- 多卡配置与实验性切分模式可能因 llama.cpp 版本、模型或设备组合加载失败；请优先使用单卡或 layer 模式。
