llama-web 1.1.0：让 `/v1` 网关能完整转发语音转写、图片编辑、视频生成这类「表单上传」和「异步任务」接口，并给接入的外部服务加了「关闭 llama-web 时一起停止」开关。相较 1.0.0：

## 新增

- **表单请求按 `model` 字段路由**：`/v1/audio/transcriptions`、`/v1/images/edits` 这类用 `multipart/form-data` 上传的接口，现在读取表单里的 `model` 字段，路由规则和 JSON 请求一致（外部上游优先，本地支持「名字:方案」）。发往外部上游时会去掉前缀、还原上游自己的模型 id，其余字段和文件原样保留；发往本地 llama-server 时请求体原样转发。之前这类请求会返回 400 `no_model`，或误落到本地正在运行的模型。
- **异步任务按任务 id 转发**：`POST /v1/videos` 创建任务成功后，llama-web 记下「任务 id → 创建它的上游」，之后的 `GET` / `HEAD` / `DELETE /v1/videos/{id}`（含 `/content` 下载）自动转发到同一个上游，下载逐块透传不整体缓存。这样文生视频、图生视频经 llama-web 可以走完「下单 → 轮询 → 下载」。任务映射保存在 `data/jobs.json`，重启后仍有效，保留 7 天、最多 2000 条。
  - 只有创建任务的一方能查：公网调用按 API key 区分，同一个 key 才能查；本机和局域网算一组。别人的、未知的、过期的 id 一律返回 404 `job_not_found`，不会落到本地模型。
  - 机制是通用的，目前只登记了 `/v1/videos`。
- **「关闭 llama-web 时一起停止」开关**：「接入」页里，填了启动命令的外部服务多了这个开关，默认关（保持原来的行为：llama-web 退出后服务继续运行）。打开后，llama-web 正常退出时会结束这次从这里启动的服务（整棵进程树）。
- 接入的「启动命令」教程里，给 AI 助手的提示词更严格：要求写绝对路径、不用 shell 特性、直接运行服务、不要猜。

## 修复

- Windows 桌面版：以前关掉桌面版会把从「接入」页启动的外部服务一起结束，和「退出后继续运行」的规则不符。现在默认保留的服务会在壳的 Job 之外启动，重启 llama-web 后仍在运行，重启前建的异步任务可以继续查询和下载。启动不成功时会退回普通启动，并在日志里说明「会随桌面版退出而停止」。
- 查不到任务时返回的 404 `job_not_found` 提示有中英文案，说明可能的原因（不是经 llama-web 创建、已过 7 天保留期、或不是当前调用方创建的）。

## 已知限制

- 开关只停 llama-web 自己拉起的进程树。服务另外启动的后端（例如视频接口后面单独运行的 ComfyUI）不会被停止，它们占用的显存也不会释放。
- 表单请求不做图片压缩，也不做加载期间的 SSE 心跳；表单里的 `stream` 不识别。
- 真机验证情况：异步任务（创建、状态、下载、未知 id、重启后仍可查）和「开关关着时重启后服务仍在运行」已在 Windows 桌面版上验证。**没有在真机上验证**的两项：开关打开时退出会停止服务（有单元测试和 macOS 真实进程测试覆盖），以及 llama-server 在壳崩溃时仍被清理。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留，卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
