llama-web 1.7.0：知识库的条目管理与外部 agent 接入，以及跟进 llama.cpp v1.0.0。相较 1.6.0：

## 新增

- **知识库条目、版本与回收站**：知识库里除了原文，还可以有可编辑的条目（带标签）；每次修改保留版本，可以对比、回退；删除进回收站，可恢复；有变更记录和每库的使用说明。
- **知识库界面**：「知识库」页选中库后分「条目 / 历史 / 回收站 / 变更记录 / 使用说明」等标签页，支持搜索、标签筛选，遇到版本冲突时给出对比。
- **外部接入**：REST（`/v1/kb`）和 MCP（`/v1/mcp`，Streamable HTTP）两种方式，外部 agent（Claude Code、Cursor、Cherry Studio 等）可以读写知识库；API key 可以限定可访问的知识库、并单独开关写权限。「接入」页里有 MCP 地址与说明。
- **跟进 llama.cpp v0.6 – v1.0.0**：识别新的 GGUF 量化类型（NVFP4、Q1_0、Q2_0、F8_E4M3）；KV 缓存支持 `f8_e4m3`；设备与切分模式、可用参数从运行库的 `--help` 解析；运行库的「发现新版」带稳定版号；内存估算与加载前检查相应更新。

## 升级说明

- 知识库数据库自动升级到新版本结构（条目、版本、变更记录）；API key 设置文件自动升级，旧配置保留。
- 已保存、含 llama.cpp 已移除参数（如 `--defrag-thold`）的方案不会被主动标出，打开编辑检查时才报错。

## 已知限制

- 以下都没有真机验证：真实 MCP 客户端的连接与写入；通过公网入口访问知识库；真实向量引擎下的条目状态；v1.0.0 运行时的 GPU 加载与 `f8_e4m3` 的实际显存。
- 外部 agent 的写入不会推送到界面，需要点刷新。
- 「在最新版本上保存我的修改」会用你的草稿覆盖别人的改动（冲突提示后主动选择才会发生）。
- `/v1/kb`、`/v1/mcp` 的调用不进「请求记录」，写操作记在知识库的变更记录里。
- 设置页在约 800 宽时左侧分区导航会压在内容上（原有问题，未处理）。
- 1.6.x 的已知限制不变。

## macOS 说明（请先读）

- 只提供 **Apple Silicon（M 系列，arm64）**；Intel Mac 没有构建，也不要用 Rosetta 代替。系统要求 macOS 13 及以上（来自 Bun 的要求，没有在 13 上实测）。
- 安装包只做了 ad-hoc 签名，**没有 Apple 开发者证书、没有公证**，所以**首次打开 macOS 会警告，不是无提示安装**。请只从本项目 Release 下载，并核对 `SHA256SUMS` 中的校验值。首次打开的做法见 `docs/macos-desktop.md`。
- Mac 版没有应用内更新：有新版本时，下载新版 DMG 替换“应用程序”里的旧应用，数据保留在用户目录。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或「设置 → llama.cpp 版本」里联网下载 macOS 版 llama.cpp。只当 API 网关用时不需要。

## Windows 说明

- 提供 Windows 11 x64 安装包，MIT 许可，未做代码签名；请仅从本项目 Release 下载并核对 `SHA256SUMS`。
- 可在应用的「设置 → 关于与更新」安装，或下载安装包覆盖安装；配置与数据保留（设置文件会自动升级到新版本），卸载时不要勾选「删除应用数据」。
- 安装包不含 llama.cpp 或模型；要跑本地模型时，在新手引导或设置里联网下载 llama.cpp。只当 API 网关用时不需要。
