# llama-web 真实界面参考（用于重绘）

所有界面都按真实产品重绘，**以本文件和源码为准，不要凭印象画**。文案出自 `i18n/zh-CN.ts`，样式出自 `app/assets/css/main.css`。拿不准时直接读下面列出的源文件。视频统一用**深色模式**。

## 1. 视觉规范

**字体**
- 正文：`'Geist Variable', 'PingFang SC', 'Microsoft YaHei', system-ui`。
- 等宽：`'Geist Mono Variable', ui-monospace, Consolas`。
- 界面基准字号 14px，数字用 `tabular-nums`。
- 视频里整个界面窗口按约 1.5–1.8 倍放大，保证 1080p 下看得清。

**深色模式色值**

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面背景 | `--lw-bg` | `#17181b` |
| 卡片底色 | `--lw-surface` | `#1f2125` |
| 次级卡片 / 选中项 | `--lw-surface-2` | `#26282d` |
| 下沉区域（输入框、分段轨道） | `--lw-sunken` | `#1b1c20` |
| 边框 | `--lw-border` | `#2d3036` |
| 强边框 | `--lw-border-strong` | `#3b3f46` |
| 正文文字 | `--lw-text` | `#e4e6ea` |
| 次要文字 | `--lw-muted` | `#a0a7b1` |
| 弱化文字 | `--lw-dim` | `#878e99` |
| 强调色（唯一） | `--lw-accent` | `#4f5bd5` |

**卡片**：`.lw-card`，圆角 14px、1px 边框、阴影 `0 1px 2px rgba(0,0,0,.25)`。

**AppCard**：标题 15px 半粗体，可带一行 12px 弱化提示，右上角放操作按钮。内边距：头部上 18、下 6，主体上 10、下 18，左右 20。

**页头**：标题 h1 24px 半粗体；下面一行 13px 次要文字；右侧放操作按钮。

**状态胶囊 `.lw-st`**：高 22px，全圆角，12px 字重 500，前面一个 7px 圆点。

| 状态 | 样式 |
|---|---|
| 就绪 | 绿字，12% 绿底 |
| 加载中 | 琥珀字，13% 琥珀底，圆点闪烁（周期 1.2 秒） |
| 失败 | 红色 |
| 已停止 | 弱化文字，下沉底色 |

**标签 `.lw-chip`**：高 22px，圆角 6，带边框，`surface-2` 底，12px 次要文字。强调版底色用 `accent-soft`，文字用 `accent-ink`。

**分段控件 `.lw-seg`**：下沉色轨道，内边距 3，圆角 10；按钮高 30，圆角 7。选中项用卡片底色并带阴影。

**进度条 `.lw-bar`**：高 6px，下沉色底，强调色填充；警告版琥珀色，错误版红色。

**导航项**：高 40，圆角 9，次要文字。选中项：卡片底色、边框、阴影、字重 500，图标变成强调色。

**按钮**（Nuxt UI）
- 主按钮：强调色实底、白字。
- 描边按钮：透明底、强边框。
- 幽灵按钮：无边框。
- 圆角约 6px，图标在左。

**图标**：Lucide 线条图标，下文写作 `i-lucide-xxx`。重绘时用 SVG 路径还原，线宽 2。

## 3. 新手引导 `/setup`（`app/pages/setup.vue`）

**容器与页头**
- 内容居中，最大宽度 760px。
- 标题「欢迎使用 llama-web」。
- 副标题「先选一种用法。每完成一步会自动打勾；可以先去别的页面看看，左侧的「新手引导」会一直在，直到你点「完成」或「先跳过」。」

**模式卡（两张）**：选中的那张用强调色边框，图标也变成强调色。
- cpu 图标「运行本地模型」，说明：「用 llama.cpp 在这台电脑上跑 GGUF 模型，四步完成。」
- plug 图标「只接入外部 API」，说明：「不需要 llama.cpp：把 vLLM、Ollama、云端 API 等 OpenAI 兼容服务接进来，客户端只连 llama-web。」

**步骤卡的样式**
- 每步一张卡片，左侧是 28px 圆形序号。
- 未完成：强调色浅底 + 强调色数字。
- 已完成：强调色实底 + 白色对勾。
- 当前步骤（第一个没完成的）：卡片用强调色边框。

**本地路线的四步**
1. **选择模型目录**
   - 说明：「模型 .gguf 文件所在的文件夹，会递归扫描子目录。可以添加多个，之后在设置页增删、停用。」
   - 主按钮（folder-open 图标）「选择文件夹…」。
   - 等宽输入框，后面跟描边按钮「添加并扫描」。
   - 结果：「已添加的目录」列出等宽路径，绿色字「在这个目录里找到 {n} 个模型文件。」
2. **安装 llama.cpp 运行库**
   - 说明：「真正跑模型的程序，来自官方发布页，下载后会校验。只需要装一次。」
   - 未安装时显示「还没有安装运行库。」和按钮（download 图标）「下载并安装」。
   - 下载过程中按钮变成「正在下载…」，状态依次显示「正在查询最新版本 / 正在下载 … / 正在解压 …」。
   - 完成后显示绿色「已安装：b11146」。
3. **启用模型**
   - 说明：「在「模型」页的「扫描发现」里，点想用的模型旁的「启用」。」
   - 按钮（arrow-right 图标）「去启用模型」。
   - 完成后显示绿色「已启用 {n} 个模型。」
4. **启动并确认**
   - 说明：「在「模型」页点「启动」。第一次启动会问你思考、视觉、MTP 三个选项，之后就能用 API 或聊天客户端连接了。」

**网关路线的三步**
1. **添加外部服务**：说明「填写服务的地址（含 /v1）和它的 API key。名称会成为模型前缀，客户端用「名称-模型id」调用。」
2. **读取模型列表**：按钮「测试连接 · {name}」，完成后显示「可用模型 {n} 个。」
3. **在客户端里接入 llama-web**
   - Base URL：`http://<局域网地址>:5001/v1`
   - model：`名称-模型id`
   - API key：「局域网不校验，随便填一个即可」

**底部**：有进度后，按钮从描边「先跳过」变成主按钮「完成，去总览」。

## 10. 不能出现在视频里的内容

- 真实路径、域名、key：示例只用 `X:\models`、`/Users/me/...`、`example.com`、局域网 IP。
- 未实现或未验证的能力：Linux、Intel Mac、从源码编译 llama.cpp、AMD / Intel 显卡、多用户登录、历史速度图表、上游负载均衡与故障转移、开机自启与托盘、Mac 应用内更新，以及 Mac 版已签名或公证。
- 不要把 vLLM / Ollama / Strata / NInfer 说成「被管理」：只能说「接入」和「转发」；对本机服务只能说「启动 / 关闭」。
